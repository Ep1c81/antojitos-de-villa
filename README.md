# 🐙 Antojitos de Villa - Website Landing Page

Sitio web profesional, reactivo y moderno para el restaurante **Antojitos de Villa**, especializado en mariscos frescos y comida tradicional costarricense.

## 🚀 Características
- **Hero Video Background:** Video looping sumergible de vida marina para transmitir el concepto de frescura marina.
- **Acceso Directo a WhatsApp:** Botones de pedido express (2249-3700) e integración directa para reservas.
- **Dynamic Menu:** Tab interactivo que alterna entre menú marino y platos tradicionales ticos.
- **FOMO Triggers:** Indicadores de disponibilidad limitada de mesas en tiempo real para acelerar reservas.
- **Diseño Dorado Premium:** Estética oscura elegante con acentos dorados.
